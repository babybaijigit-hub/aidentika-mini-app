# AI Study Assistant

Проект развивается поэтапно. Сейчас репозиторий содержит Telegram Mini App на GitHub Pages и начальный каркас Python-бота.

## Что уже работает
- Mini App строит локальный учебный план по введённым теме, предмету и типу работы; план можно скопировать.
- Python-бот на aiogram 3 показывает меню, проводит пошаговый сбор данных для учебной работы или презентации и сохраняет запросы в SQLite.
- В коде нет токенов. Секреты задаются переменными окружения.

Важно: план и презентационные слайды на текущем этапе — шаблонные заготовки, не генерация AI. Остальные разделы меню будут реализовываться по этапам; для AI потребуется отдельный API-ключ и сервер.

## Запуск бота локально
Нужен Python 3.11+.

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r bot/requirements.txt
```

Скопируйте `.env.example` в `.env`, вставьте свой токен локально в `BOT_TOKEN` (не отправляйте его в чат и не коммитьте `.env`), затем запустите:

```bash
python -m bot.main
```

Бот использует long polling. Одновременно должен работать только один polling-процесс для данного токена. SQLite-файл создаётся автоматически в `data/`.

## Mini App
GitHub Pages: https://babybaijigit-hub.github.io/aidentika-mini-app/

Проверка Mini App в браузере работает без токена. Для открытия из Telegram нужно будет установить опубликованный HTTPS URL в настройках существующего бота через BotFather. Токен для Mini App не нужен.

## Дальнейшие этапы
1. Подключить Mini App к боту и проверить отправку данных.
2. Подключить AI-провайдера через секреты хостинга и добавить обработку ошибок/лимитов.
3. Реализовать предметные модули, OCR изображений/PDF и поиск проверяемых источников.
4. Добавить экспорт DOCX/PDF/PPTX, профиль, историю, планировщик и напоминания.
5. Настроить серверный деплой и тестирование.

Не добавляйте `.env`, токен бота или API-ключи в GitHub.
